## 5. Descrição de cada disciplina

### 5.1) Sistemas e Redes

- **Horas:** 200 h
- **Ano:** 1.º e 2.º anos
- **Objectivo:** Criar a base técnica do curso e desenvolver progressivamente competências de sistemas, redes, serviços e segurança.
- **Área da disciplina:** Infraestruturas informáticas, hardware, sistemas operativos, redes e segurança base.
- **Descrição:** Disciplina vertical entre o 1.º e o 2.º ano. No 1.º ano, concentra os conteúdos concretos de equipamentos, sistemas operativos, software e instalação básica de redes. No 2.º ano, quando os alunos já compreendem aplicações web, aprofunda protocolos, serviços e políticas de segurança.

| Ano       | Código  | UC                                                                             |   Horas |
| --------- | ------- | ------------------------------------------------------------------------------ | ------: |
| 1.º       | UC01989 | Montar, instalar e manter equipamentos informáticos                            |      40 |
| 1.º       | UC02829 | Instalar, configurar e parametrizar sistemas operativos                        |      40 |
| 1.º       | UC01990 | Instalar, configurar e atualizar software complementar aos sistemas operativos |      20 |
| 1.º       | UC02817 | Instalar e interligar redes                                                    |      20 |
| 1.º       | UC00616 | Implementar as normas de segurança e saúde no trabalho no setor de Informática |      20 |
| 2.º       | UC00241 | Configurar protocolos e serviços de rede                                       |      40 |
| 2.º       | UC00613 | Gerir políticas de segurança em sistemas informáticos                          |      20 |
| **Total** |         |                                                                                | **200** |

**Articulação recomendada:**

1. No 1.º ano, preparar e utilizar os equipamentos, sistemas operativos e redes básicas.
2. No 2.º ano, relacionar protocolos e serviços com a programação web server-side.
3. Aplicar políticas de segurança aos serviços, utilizadores e comunicações utilizados nas aplicações.

### 5.2) Fundamentos de Programação

- **Horas:** 115 h
- **Ano:** 1.º ano
- **Objectivo:** Introduzir pensamento computacional, algoritmia, lógica e programação através de uma progressão pedagógica apoiada em Python.
- **Área da disciplina:** Algoritmia e fundamentos de programação.
- **Descrição:** Disciplina de entrada na programação. Começa com representação de algoritmos, avança para estruturas de controlo e funções e termina com a criação de aplicações em Python.

| Ano       | Código             | UC                                                  |   Horas |
| --------- | ------------------ | --------------------------------------------------- | ------: |
| 1.º       | UC00245            | Desenvolver algoritmos                              |      25 |
| 1.º       | UC00606            | Desenvolver programas em linguagem estruturada      |      45 |
| 1.º       | UC00618 (Opcional) | Criar aplicações em linguagem de programação Python |      45 |
| **Total** |                    |                                                     | **115** |

**Articulação recomendada:**

1. Algoritmos, fluxogramas e pseudocódigo.
2. Condições, ciclos, funções e estruturas de dados em Python.
3. Ficheiros, módulos, bibliotecas, testes e pequenas aplicações.

### 5.3) Bases de Dados

- **Horas:** 85 h
- **Ano:** 1.º ano
- **Objectivo:** Desenvolver competências de modelação e gestão de dados, começando pelo modelo relacional e evoluindo para bases de dados não relacionais.
- **Área da disciplina:** Análise de sistemas e bases de dados.
- **Descrição:** Disciplina dedicada ao ciclo de dados das aplicações. Os alunos começam por modelar e implementar bases de dados relacionais com SQL e terminam comparando o modelo relacional com diferentes modelos NoSQL e aplicando bases de dados orientadas a documentos.

| Ano       | Código             | UC                                              |  Horas |
| --------- | ------------------ | ----------------------------------------------- | -----: |
| 1.º       | UC00602            | Modelar bases de dados relacionais              |     20 |
| 1.º       | UC02830            | Desenvolver uma base de dados com linguagem SQL |     45 |
| 1.º       | UC00664 (Opcional) | Criar bases de dados NoSQL                      |     20 |
| **Total** |                    |                                                 | **85** |

**Articulação recomendada:**

1. Modelação conceptual e lógica.
2. Tabelas, relações, integridade e consultas SQL.
3. Comparação entre modelos relacionais, documentais, chave-valor, coluna e grafo.
4. Critérios para decidir quando utilizar SQL ou NoSQL.

### 5.4) Desenvolvimento de Aplicações

- **Horas:** 290 h
- **Ano:** 1.º, 2.º e 3.º anos
- **Objectivo:** Construir aplicações progressivamente mais completas, começando no frontend, avançando para programação server-side e terminando com integração de dados, aplicações web, mobile e inteligentes.
- **Área da disciplina:** Desenvolvimento aplicacional frontend, backend, web, mobile e integração de IA.
- **Descrição:** Disciplina vertical de implementação. No 1.º ano, os alunos constroem interfaces e adotam práticas de controlo de versões. No 2.º ano, iniciam a programação web server-side em articulação com protocolos e serviços de rede. No 3.º ano, integram as aplicações com dados e desenvolvem os componentes web, mobile e inteligentes do produto final.

| Ano       | Código             | UC                                                                              |   Horas |
| --------- | ------------------ | ------------------------------------------------------------------------------- | ------: |
| 1.º       | UC02833            | Conceber aplicações para a web na vertente frontend                             |      45 |
| 1.º       | UC00617 (Opcional) | Utilizar serviços Git e GitHub                                                  |      20 |
| 2.º       | UC02834            | Desenvolver programação para a web                                              |      50 |
| 3.º       | UC02831            | Desenvolver uma interface para a base de dados com uma linguagem de programação |      40 |
| 3.º       | UC02832            | Planear, instalar e configurar um sistema de gestão de conteúdos                |      40 |
| 3.º       | UC00621 (Opcional) | Criar aplicações em React                                                       |      25 |
| 3.º       | UC02835            | Desenvolver aplicações para dispositivos móveis                                 |      45 |
| 3.º       | UC00623 (Opcional) | Programar com sistemas de Inteligência Artificial                               |      25 |
| **Total** |                    |                                                                                 | **290** |

#### Progressão da disciplina

**1.º ano - Interface e práticas de desenvolvimento**

- HTML, CSS e JavaScript;
- interfaces responsivas e acessíveis;
- Git, commits, branches e colaboração através do GitHub.

**2.º ano - Programação server-side**

- programação server-side;
- APIs e arquitetura cliente-servidor;
- pedidos e respostas HTTP;
- validação e tratamento de erros;
- aplicação dos protocolos e serviços estudados em Sistemas e Redes;
- cinco horas de segurança web prática, articuladas com a UC00613, incluindo validação de dados, autenticação, autorização, sessões e prevenção de vulnerabilidades comuns.

**3.º ano - Integração de dados e aplicação multiplataforma**

- interface entre a aplicação e a base de dados;
- sistema de gestão de conteúdos para administração do produto;
- interface web em React;
- aplicação móvel;
- funcionalidade de IA integrada.

No 3.º ano, as cinco UC devem contribuir para o mesmo produto:

- a interface de dados liga a aplicação ao sistema de persistência;
- o sistema de gestão de conteúdos gere a informação e o backoffice;
- React disponibiliza a interface web;
- a aplicação móvel disponibiliza outro ponto de acesso ao produto;
- a IA acrescenta uma funcionalidade concreta, testável e adequada ao problema.

### 5.6) Projeto de Software

- **Horas:** 90 h
- **Ano:** 3.º ano
- **Objectivo:** Planear, desenvolver, proteger, testar e documentar um produto de software que integre as aprendizagens das restantes disciplinas.
- **Área da disciplina:** Projeto, engenharia de software, segurança aplicada e documentação técnica.
- **Descrição:** Disciplina integradora do 3.º ano. O projeto é o elemento central; a segurança é tratada como requisito do produto e a documentação como um dos seus entregáveis. As três UC são avaliadas através do mesmo projeto, evitando trabalhos independentes e sem relação entre si.

| Ano       | Código  | UC                                                               |  Horas |
| --------- | ------- | ---------------------------------------------------------------- | -----: |
| 3.º       | UC02837 | Desenvolver projetos de programação                              |     45 |
| 3.º       | UC02836 | Programar parâmetros de segurança no desenvolvimento de software |     25 |
| 3.º       | UC02823 | Produzir relatórios e documentos técnicos                        |     20 |
| **Total** |         |                                                                  | **90** |

#### Organização da disciplina

**Projeto - 45 horas**

- definição do problema e dos utilizadores;
- requisitos e planeamento;
- arquitetura e protótipos;
- implementação e integração;
- testes e apresentação do produto.

**Segurança aplicada - 25 horas**

- validação de dados;
- autenticação e autorização;
- gestão segura de palavras-passe e segredos;
- proteção de APIs e bases de dados;
- prevenção de vulnerabilidades;
- privacidade, RGPD e riscos associados à IA.

**Documentação técnica - 20 horas**

- requisitos e decisões de arquitetura;
- documentação da API e da base de dados;
- plano e resultados de testes;
- manual de instalação e utilização;
- relatório técnico e apresentação final.

### 7.2) Princípios de implementação

Para que a redução seja pedagogicamente sustentável:

1. Git é ensinado na UC00617 e utilizado em todas as UC seguintes.
2. Testes e depuração acompanham cada aplicação, sem uma nova introdução completa em cada linguagem.
3. A documentação é produzida progressivamente e consolidada na UC02823.

## 9. Articulação curricular do 3.º ano

As disciplinas do 3.º ano trabalham sobre o mesmo produto, mas têm responsabilidades diferentes.

### 9.1) Desenvolvimento de Aplicações

Fornece e implementa os componentes tecnológicos:

- integração da aplicação com a base de dados;
- gestão de conteúdos e backoffice;
- interface web em React;
- aplicação móvel;
- funcionalidade de Inteligência Artificial.

### 9.2) Projeto de Software

Gere a qualidade e a conclusão do produto:

- requisitos e planeamento;
- arquitetura e integração;
- segurança e privacidade;
- testes;
- documentação;
- apresentação final.

### 9.4) Exemplo de produto integrador

Uma plataforma escolar ou comunitária com:

- backoffice para gestão de utilizadores e conteúdos;
- aplicação web em React;
- aplicação móvel;
- API e base de dados;
- chatbot, recomendação ou classificação inteligente;
- autenticação e autorização;
- aplicação de requisitos de segurança e privacidade;
- testes e documentação técnica.

O produto é desenvolvido tecnicamente em **Desenvolvimento de Aplicações** e conduzido, protegido, testado e documentado em **Projeto de Software**.
